## 2. 关键页面

### 2.1 工作台

- 按角色显示个人待办、项目概况、逾期事项、风险和审批。
- 项目经理增加项目健康度、里程碑和资源冲突卡片。
- 部门负责人只展示本部门成员与任务数据。
- 客户展示需求状态、待验收交付和授权文档。

### 2.2 项目详情

页头：项目名称、状态、项目经理、计划时间、实际时间、完成率和风险等级。

页签：概览、里程碑、看板、甘特图、任务、成员、风险、文档、成本、交付、动态。

### 2.3 任务详情

- 基本信息与时间字段
- 负责人和参与人
- 状态操作区（根据权限动态展示）
- 预计工时与完成工时
- 子任务、附件、评论、风险和操作历史
- 交付版本与验收记录

### 2.4 待分派需求池

- 展示来源、提交人、客户、主题、接收时间和自动识别结果。
- 支持补充字段、指定负责人、选择项目类型、关联项目、发起审批。
- 管理员可识别并合并重复需求。

### 2.5 资源负荷页

- 时间轴展示成员已分配工时和可用工时。
- 标记超负荷、任务时间冲突及跨项目占用。
- 按部门、成员、项目和时间筛选。

### 2.6 交付验收页

- 展示交付版本、任务清单、文档、提交人和提交时间。
- 客户执行通过、驳回或要求修改，并填写意见。
- 展示完整历史版本和每次验收结果。

## 3. 移动端导航建议

底部导航：工作台、需求、任务、消息、我的。

验收、附件上传、任务状态更新和工时填报采用移动端快捷操作；复杂的流程配置、甘特图编辑和系统管理保留在 Web 端。
