## 现场验收项

1. 在目标 Docker 主机执行 `docker compose up -d --build` 并检查三个服务健康状态。
2. 使用企业 SMTP、企业微信机器人和 Teams Webhook 各发送一条真实通知。
3. 使用企业 OIDC 身份提供方登录预建账号，并确认未建账号被拒绝。
4. 由邮件网关和企业微信应用调用需求接入 API，确认用户名映射和待分派入池。
5. 对企业文件服务执行一次上传、下载和版本更新。
6. 执行备份并在隔离环境恢复，验证数据库、文档和 Flyway 版本。
